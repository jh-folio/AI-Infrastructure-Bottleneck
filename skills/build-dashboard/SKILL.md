# 저장 결과 표시 요청

[실행 계약](../../plugin/workflows/RUNTIME_GUIDE.md)의 D5 절을 읽고 실제 report_id를 확인한다. export-dashboard로 새 HTML을 내보내고 실제 파일을 열어 준다. 화면에는 해당 보고서의 snapshot에 포함된 근거·관계만 표시한다. 이후 자료를 과거 화면에 끼워 넣지 않는다. 화면 요청 자체로 새로운 연구를 시작하지 않는다.

관계가 필요하면 검토된 두 판단 사이의 relation을 근거와 함께 기록하고 그 관계를 포함한 새 보고서를 생성한 후 화면으로 내보낸다. 기술 의존·관측된 지연 전파·조건부 전파를 구별하고 그래프 연결 수를 점수에 더하지 않는다. 관계 기록이 없으면 빈 관계 상태를 보여 주며 기술적으로 그럴듯한 선을 창작하지 않는다. 레이아웃 방향을 병목 순위로 설명하지 않는다. 화면 요청만으로 새 평가나 baseline 승격을 수행하지 않는다.

실제 Work에서 HTML/JavaScript가 열리는지, 구간/지역/추세 필터·원문·관계·모바일 표시가 동작하는지 확인한다. 표시 환경이 제한되면 원인과 보고서 대안을 알리고 인터랙티브 화면 성공으로 기록하지 않는다. 본문에는 자연스러운 한국어를 사용하고 내부 식별자는 검증 정보에 둔다.
