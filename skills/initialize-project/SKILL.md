# D1 합성 저장 검증

이 패키지는 최종 5개 워크플로우 중 설정/저장 시험만 노출한 개발 초안이다. 연구 데이터 수집·병목 평가·투자 분석·화면·예약 실행을 구현했다고 안내하지 않는다.

[실행 안내](../../tests/D1_WORK_HANDOFF.md)를 먼저 읽는다. 사용 가능한 실행/파일 도구와 현재 환경이 Work Cloud인지 로컬인지 확인한다. 설치 루트가 쓰기 가능한 사용자 저장 경로라고 가정하지 않는다. 실제 쓰기 가능하고 사용자가 허용한 위치에 존재하지 않는 합성 시험 폴더를 선택한다. 기존 사용자 폴더나 연구 DB는 초기화하지 않는다.

[저장 CLI](../../plugin/runtime/core/persistence_poc.py)와 [합성 schema](../../plugin/database/poc_schema.sql)는 패키지 안에 있다. 상대 위치를 유지해 실행한다. Python/SQLite/파일 실행이 제공되지 않으면 필요한 capability와 보존 가능한 입력을 설명한다. 이름이 비슷한 도구를 추정하거나 임시 파일만으로 Work 지속성을 선언하지 않는다.

사용자가 POC를 요청하면 안내의 실행 A를 수행하고 project_id·실제 저장 위치·내용 해시·사용자 개입·결과를 반환한다. 새 실행에서 같은 상태를 다시 찾는 실행 B는 실제 새 실행에서만 검증한다. 같은 프로세스나 세션 반복을 새 Work 세션 성공으로 바꾸지 않는다. 수동 재업로드가 필요하면 수동 복구로 표시한다.

실행 도구가 제공되면 [테스트](../../tests/test_persistence_poc.py)로 합성 데이터의 중복·실패 복구를 검증할 수 있다. 사용자 요청 없이 예약을 등록하거나 다른 작업을 만들지 않는다. 연구 데이터나 점수를 임의 생성하지 않는다. 이 패키지는 중앙 서버·별도 인증·MCP 서버를 포함하지 않는다.

## 공개자료 취득 시험

사용자가 자료 취득/재조회 POC를 요청하면 [공개 JSON 시험 안내](../../tests/D1_SOURCE_HANDOFF.md)를 읽고 수행한다. SEC_USER_AGENT는 실제 사용자 설정에서 읽으며 연락처를 추정하지 않는다. 실제 접근이 차단되면 실패로 남기고 차단 우회·점수 생성을 하지 않는다. 공개 JSON 취득은 연구 근거 채택과 다르다. ZIP 생성만 확인된 경우 설치나 POC 실행 완료로 보고하지 않는다.
